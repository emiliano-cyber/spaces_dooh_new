pública a punto de compartir máquina, cualquier ejecución de código en el proceso
web es ejecución como root en el plano de control. **Tarea abierta.**

**② HSTS de dos años sobre `demo.space-os.io`.** Medido. Un error de certificado
en ese nombre **no es saltable** desde el navegador. Por eso el certificado se
emite por **DNS-01 antes** de mover el DNS: no es preferencia, es requisito.

**③ El certificado de la máquina perdida vence el 2026-10-26.** Emitido el 28/07,
sin renovar. Es la fecha límite natural de todo este asunto.

**④ La instancia perdida puede seguir publicando a pantallas reales.** El tablero
del 10/08 decía `DOOHMAIN_PUBLISH_ENABLED=1`. **Se comprueba desde DOOHmain**, no
desde el servidor: no hay servidor. **Sin hacer.**

**⑤ El token de Cloudflare se vuelve dependencia de renovación permanente.** Si
caduca o lo revocan, la renovación falla **en silencio** y el sitio muere 90 días
después. `certbot renew --dry-run` cada dos meses es lo único que lo delata.

**⑥ La consola web de DigitalOcean corrompe las pegadas multilínea.** Pasó dos
veces (defecto ⑧ del 21/08, y otra vez hoy). Lo que funciona es **una sola
línea**.

corrió un censo entero en la máquina equivocada.
