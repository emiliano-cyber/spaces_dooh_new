# P1 - Generar la contrasena, fijarla y escribir el DATABASE_URL
# ------------------------------------------------------------
# `openssl rand -hex 32` a proposito: SOLO caracteres hexadecimales.

# `PG_URL_SEGURA` en update.sh). Con hex no hay nada que escapar.
#
# Es seguro cambiarla: hoy NADA la esta usando con exito.
