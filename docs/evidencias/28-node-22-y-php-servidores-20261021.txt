    dpkg -l | grep -E '^ii +(php|libapache2-mod-php)' || echo "sin paquetes php"
    which node; node -v 2>/dev/null; /usr/local/bin/node -v 2>/dev/null

PASO 2 · EL PADRE (no corre desde la imagen: hay que cambiarle el Node)
-----------------------------------------------------------------------
El PADRE tiene DOS instalaciones de Node y hay que cambiar las DOS
(infra/systemd/flota-reporte.service:48-54):
   root (nvm)            /root/.nvm/versions/node/v20.20.2   -> la usa npm/build
   /usr/local/bin/node   (copia)                             -> spaces-web y flota-*

a) Ver como esta hoy, y guardar la vuelta atras:
    /usr/local/bin/node -v
    cp -a /usr/local/bin/node /usr/local/bin/node-20.bak
    pm2 ls 2>/dev/null || echo "sin pm2"

b) Node 22.23.4 por nvm (root):
    source /root/.nvm/nvm.sh
    nvm install 22.23.4
    nvm alias default 22.23.4
    node -v                      # v22.23.4

c) La copia de /usr/local/bin:
    cp "$(nvm which 22.23.4)" /usr/local/bin/node
    /usr/local/bin/node -v       # v22.23.4

d) Reconstruir la app con el Node nuevo (los modulos nativos cambian de ABI;
   por eso `npm ci` y no `npm install`: ademas no reescribe el lockfile):
    cd /var/www/Spaces
    git pull
    npm ci
    npm run build
    chown -R padre:padre apps/web/.next
    systemctl daemon-reload
    systemctl restart spaces-web
    systemctl restart flota-panel flota-reporte
    systemctl list-timers flota-altas.timer --no-pager    # el timer usa el node nuevo en su proxima corrida

e) Si en (a) pm2 mostro procesos vivos, reinicia su demonio con el node nuevo:
    pm2 update

f) Comprobar:
    systemctl is-active spaces-web flota-panel flota-reporte
    readlink -f /proc/$(systemctl show -p MainPID --value spaces-web)/exe     # /usr/local/bin/node
    /proc/$(systemctl show -p MainPID --value spaces-web)/exe -v              # v22.23.4
    curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:3000/spaces-dooh/api/auth/metodos/
  -> active x3, v22.23.4 y 200. Y entrar en el PADRE desde el navegador.

VUELTA ATRAS DEL PADRE (si spaces-web no levanta):
    cp -a /usr/local/bin/node-20.bak /usr/local/bin/node
    source /root/.nvm/nvm.sh && nvm alias default 20.20.2
    cd /var/www/Spaces && npm ci && npm run build && chown -R padre:padre apps/web/.next
