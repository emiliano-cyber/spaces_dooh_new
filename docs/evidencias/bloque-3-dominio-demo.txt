# ------------------------------------------------------------
# P2 [PADRE] - lanzar certbot y PARARSE
# ------------------------------------------------------------
# El `read` del principio se come el salto de linea sobrante de
# la pegada. Si al pegarlo se queda esperando, pulsa Enter UNA

# Va a pedir DOS desafios, uno por dominio, uno detras de otro.

# >>> NO PULSES ENTER cuando imprima el primer desafio.
#     Copiame lo que salga y te devuelvo las dos lineas ya
#     armadas, una para cada consola.

# Lo que imprime, por cada dominio:
#
#   Create a file containing just this data:
#   <CADENA-LARGA-CON-UN-PUNTO>
#   And make it available on your web server at this URL:
#   http://<dominio>/.well-known/acme-challenge/<NOMBRE>
#
# El NOMBRE es la parte ANTERIOR al punto. El CONTENIDO es la
# cadena entera. Son distintos, y confundirlos es el error tipico.


# ------------------------------------------------------------
# P3 - Colocar los dos archivos, cada uno en su maquina

# UNA cosa. Sustituye EL_CONTENIDO y nada mas:
