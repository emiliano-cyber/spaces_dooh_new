## Dos fallos del propio runbook, ya corregidos en él

1. **Orden equivocado.** El PASO 0 (ensayo) usa el archivo de la migración, que
   llegaba con el `git merge` puesto en el PASO 2. Al seguirlo tal cual, el
   ensayo falló con «No such file or directory». Traer la fuente **no** cambia
   lo servido, así que el pull sube al principio: pull → ensayo → migración →
   build+reload.

2. **El primer build falló y se recargó igualmente.** `turbo` imprimió
   «Compiled successfully» y varias líneas después `Failed: web#build` — son
   fases distintas: webpack compila y luego el typecheck puede tumbarlo. El
   `pm2 reload` se lanzó sin mirar el código de salida, dejando un rato el
   estado exacto que el runbook existe para evitar: **migración aplicada con
   código viejo**.

   Repetido sin tocar nada, el build pasó limpio (exit 0). Fue transitorio y la
   aplicación nunca dejó de responder (comprobado: login 200 en ese intervalo).
   El runbook ahora avisa de mirar el código de salida antes de recargar.
